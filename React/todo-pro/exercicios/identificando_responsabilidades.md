# Identificando Responsabilidades

### Classifique cada item como _frontend_, _backend_ ou _banco de dados_:

1. **(FRONTEND)** Exibir o título de uma tarefa.
2. **(BACKEND)** Validar se uma tarefa possui título antes de salvá-la.
3. **(BANCO DE DADOS)** Armazenar a data de criação de uma tarefa.
4. **(FRONTEND)** Alterar a cor de um botão ao passar o mouse.
5. **(BACKEND)** Verificar se o usuário tem autorização para excluir uma tarefa.
