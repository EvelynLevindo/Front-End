# Exploração Orientada

**Qual arquivo contém os scripts do npm?**
+ Resposta: package.json.

**Por que `node_modules` não deve ser enviado ao Git?**
+ Resposta: Porque é uma pasta muito pesada e pode ser recriada a qualquer momento executando npm install.

**Onde ficará o código principal?**
+ Resposta: Na pasta src.

**Qual é o papel do `main.jsx`?**
+ Resposta: É o ponto de entrada que inicializa e renderiza a aplicação React no navegador.

**Qual comando cria uma versão de produção?**
+ Resposta: npm run build.
